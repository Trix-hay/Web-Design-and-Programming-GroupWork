Overview

The Course Registration System is a web-based system that allows users to manage information related to students, instructors, courses, and course registrations. Users can enroll students, add instructors, add courses, register students for courses, and drop students from courses.The system consists of several pages, each designed for a specific task. The Home Page provides an introduction to the system and navigation links to the other pages. The Enroll Student page allows users to enter information for a new student. The Add Instructor page allows users to enter instructor information. The Add Course page allows users to enter information about a course, including its semester, course number, section, meeting days and times, credit hours, instructor, and enrollment limit. The Register Course page is used to register a student for a course, while the Drop Course page is used to remove a student from a course. This manual explains the purpose of each page, describes the fields and controls available to users, and provides examples of the information that can be entered into each form.

Home Page

Summary

The Home Page is the starting page of the system. It provides a brief description of the Course Registration System and has links to other pages in the system.

Detailed Description

The Home Page contains the title of the Course Registration System at the top of the page, along with a brief description of the system. A navigation menu is located on the page and provides links to the Enroll Student, Add Instructor, Add Course, Register Course, Drop Course, User Manual, and Programmer Manual pages. Users can select a link from the navigation menu to access the corresponding page. The Home Page does not require the user to enter any information.

Enroll Student

Summary

The enroll student page allows the user to enter student information and add to the web application.

Detailed Description

The page contains a form where the user enters the student's personal and academic information. Each field should be completed with information that identifies and describes the student. It has the following fields:

1. Student First Name

Enter the student's first name.
Example: Olivia

2. Student Last Name

Enter the student's last name.
Example: Hughes

3. Student's Year

Select the student's year from the list.
Acceptable values are Freshman, Sophomore, Junior or Senior.

4. Student Major

Enter the student's major.
Example: Computer Science

5. Student Email

Enter the student's email address.
Example: oh010@marietta.edu

Add Course

Summary

The Add Course page allows users to enter information about a course that will be offered during a particular semester. The form collects information about the course, including its semester, course number, section, meeting schedule, location, credit hours, instructor, and enrollment capacity.

Detailed Description

The user enters the course information into the form. Some fields require the user to type information, while others require the user to select an option from a drop-down list. It has the following fields:

1. Semester

The user can choose the semester by selecting from the select list.
Acceptable values are spring, summer, and fall.

2. Course Prefix

The user should enter the course prefix.
Example: CSCI

3. Course Number

The user should add the course number.
Example: 101, 330 etc.

4. Course Section

The user should add the section of the course.
Example: 01, 02

5. Course Name

The user should enter the name of the course. Example: Web Design and Programming

6. Room

The user should enter the building and room number where the class is held.
Example: Selby 239

7. Days Offered

The user can choose the days the course is being offered in the select list. Acceptable values include: Monday, Wednesday, Friday; Monday, Wednesday; Tuesday, Thursday; Monday; Tuesday; Wednesday; Thursday.
Example: CSCI 330 is offered on Monday, Wednesday and Friday.

8. Time

The user can choose the times the course is offered by selecting from the select list.

Acceptable Values for Mondays are:
8:00 AM to 8:50 AM
9:00 AM to 9:50 AM
10:00 AM to 10:50 AM
11:00 AM to 11:50 AM
12:00 PM to 12:50 PM
1:00 PM to 1:50 PM
2:00 PM to 2:50 PM
3:00 PM to 3:50 PM

Acceptable values for Monday, Wednesday are:
9:00 AM to 10:50 AM
1:00 PM to 2:15 PM
1:00 PM to 2:50 PM
2:00 PM to 3:15 PM

Available times for Tuesday, Thursday are:
8:00 AM to 9:15 AM
9:30 AM to 10:45 AM
11:00 AM to 12:15 PM
1:00 PM to 2:15 PM
2:30 PM to 3:45 PM

Available times for any single day are:
1:00 PM to 4:00 PM
2:00 PM to 5:00 PM
7:00 PM to 9:30 PM

The Monday, Wednesday, Friday list contains all of the possible times for 50 minute classes. The Monday, Wednesday list contains all the possible times for Monday, Wednesday classes (either 75 minutes or 110 minutes). The Tuesday, Thursday list contains all possible times for 75 minute classes. The fourth list contains the possible times for labs and evening courses.

9. Credit Hours

The user should enter the credit hours for the course.
Example: 1, 3 etc.

10. Instructor First Name

Enter the instructor's first name.
Example: Matthew

11. Instructor's Last Name

Enter the instructor's last name.
Example: Williamson

12. Enrollment Cap

Enter the maximum students that can register for that particular course in a semester.
Example: 15
