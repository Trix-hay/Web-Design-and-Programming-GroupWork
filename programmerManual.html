Overview of the Course Registration System.

The Course Registration System is a web application designed to automate the process of managing student course registration. The system is structured to allow users to add students, instructors, and courses through Web forms. Users will also be able to register students for courses and drop students from courses. The Web interface is implemented using HTML and CSS. The HTML pages provide the structure of the application and contain the forms and input elements used to collect information. Each form element is assigned a unique id attribute so that the elements can be referenced by JavaScript and other application components in later modules. CSS is used to provide a consistent layout and visual style across the Web pages. The complete application is designed to use JavaScript, Node.js, and Express for application and server-side functionality and SQLite for database storage. The database will store information associated with students, instructors, courses, and course registrations. In Module 1, the primary focus is the Web interface, so the HTML forms have been created but do not yet perform database operations or other application functionality. The application is divided into multiple HTML pages, with each page responsible for a specific part of the course registration process. The pages share a consistent layout and navigation structure so that users and developers can move between the different components of the system.

Summary of Each Page Content

HomePage.html

The Home page serves at the starting page for the Course Registration Sysytem. It contains the site header, navigation menu, main content area and footer.

enrollstudent.html

This page contains the Web form used to collect student information, including the student's first name, last name, year, major, and email address.

addinstructor.html

This page contains the Web form used to collect instructor information, including the instructor's first name, last name, department, rank, and email address.

addcourse.html

This page contains the Web form used to collect course information, including the semester and year, course prefix and number, section, course name, room, days offered, time, credit hours, instructor information, and enrollment cap.

registercourse.html

This page contains the Web form used to collect the information needed to register a student for a course.

dropcourse.html

This page contains the Web form used to collect the information needed to drop a student from a course.

ProgrammerManual.html

Contains the technical documentation for the Course Registration System, including the system overview, HTML page descriptions, file organization, form elements, and functions.

Stylesheet.css

Contains the CSS rules used to provide consistent styling for the header, footer, navigation links, forms, and buttons throughout the website.
