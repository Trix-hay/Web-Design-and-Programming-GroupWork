Module 1

Drew Martin, Maisee Carrier, Beatrice Hayfron

This project is a work in progress layout for a student to search and enroll for classes and professors as well as register/drop courses.

The technologies this is meant for are computers and mobile devices on a browser.

The directory is structured neatly with a single-level directory. Every file has a unique name and is easy to get from one to the other.

The project starts by opening "homepage.html" with all of the options for the student listed. From there it is easy to navigate from page to page with no issue.
