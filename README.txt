Course Registration System: Group Project Module 1
For CSCI 330: Web Design and Programming

Drew Martin, Maisee Carrier, Beatrice Hayfron

This project is a work in progress layout for a student to search and enroll for classes and professors as well as register/drop courses. It utilizes HTML and CSS to create a simple, visually pleasing course registration system.

The technologies this is meant for are computers and mobile devices on a browser.

The directory is structured neatly with a single-level directory. Every file has a unique descriptive name and it is easy to get from one to the other.

The project starts by opening "homepage.html" with all of the options for the student listed. From there, it is easy to navigate from page to page with no issue. Since this module focused mainly on creating the HTML and CSS for the pages, there is limited functionality besides traveling between pages. The header on each page (Course Registration System) functions as a link back to the home page so users can navigate easily from any form page back to the home page. The manuals also include the navigation pane seen on the home page for simplicity purposes.
