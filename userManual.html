Overview

The Course Registration System allows users to add and manage students,Instructors, courses and course Registrations as well as dropping courses.

Home Page

The Home Page is the starting page of the system. It provides a brief description of the course Registration system and has links to other pages in the system.

Enroll Student

The enroll student page allows the user to enter student information and add to the web application. This page is a web form that allows users to input some information about the student to be entered into the web application. It has the following fields;

1. Student FirstName

Enter the Student's First Name.
Example: Olivia

2. Student LastName

Enter the Student's Last Name.
Example: Hughes

3. Student's Year

Select the student's year from the list.
Acceptable Values are Freshman, Sophomore, Junior or Senior.

4. Student Major

Enter the Student's Major.
Example: Computer Science

5. Student Email

Enter the Student's email address.
Example: oh010@marietta.edu

Add Instructor

The add Instructor page is a web form that allows the user to add an instructor to the web application. It has the following fields;

1. Instructor FirstName

Enter the Instructor's First Name.
Example: Matthew

2. Instructor's LastName

Enter the Instructor's Last Name.
Example: Williamson

3. Instructor's Department

Enter the Instructor's Department.
Example: Computer Science

4. Instructor's Rank

Select the rank of the Instructor form the select list.
Acceptable values are Instructor,Assistant Professor, Associate Professor and Professor.

Add Course

The Add Course is a web form page that allows the user to add a course. It has the following fields;

1. Semester

The user can choose the semester by selecting from the select list.
Acceptable Values are spring, summer and fall.

2. Course Prefix

The user should enter the course prefix.
Example: CSCI

3. Course Number

The user should add the course number for easy identification. Example: 101, 330 etc.

4. Course Section

The user should add the section of the course.
Example: 01,02

5. Course Name

The user should enter the name of the course.

6. Room

The user should enter the building and room number where the class is held. Example: Selby 239

7. Days Offered

The user can choose the days the course is being offered in the select list. Acceptable values include: Monday, Wednesday, Friday; Monday, Wednesday; Tuesday, Thursday; Monday; Tuesday; Wednesday; Thursday.
Example: CSCI 330 is offered on Monday, Wednesday and Friday.

8. Time

The user can choose the times the course is offered by selecting from the select list. Acceptable Values for Mondays are;
8:00 AM to 8:50 AM
9:00 AM to 9:50 AM
10:00 AM to 10:50 AM
11:00 AM to 11:50 AM
12:00 PM to 12:50 PM
1:00 PM to 1:50 PM
2:00 PM to 2:50 PM
3:00 PM to 3:50 PM
Acceptable values for Monday, Wednesday are;
9:00 AM to 10:50 AM
1:00 PM to 2:15 PM
1:00 PM to 2:50 PM
2:00 PM to 3:15 PM
Available times for Tuesday, Thursday are; 8:00 AM to 9:15 AM
9:30 AM to 10:45 AM
11:00 AM to 12:15 PM
1:00 PM to 2:15 PM
2:30 PM to 3:45 PM
Available times for any single day are;
1:00 PM to 4:00 PM
2:00 PM to 5:00 PM
7:00 PM to 9:30 PM
The Monday, Wednesday, Friday list contains all of the possible times for 50 minute classes. The Monday, Wednesday list contains all the possible times for Monday, Wednesday classes (either 75 minutes or 110 minutes). The Tuesday, Thursday list contains all of the possible times for 75 minute classes.The fourth list contains the possible times for labs and evening courses.

9. Credit Hours

The user should enter the credit hours for the course.
Example: 1,3 etc

10. Instructor FirstName

Enter the Instructor's First Name.
Example: Matthew

11. Instructor's LastName

Enter the Instructor's Last Name.
Example: Williamson

12. Enrollment Cap

Enter the maximum students that can register for that particular course in a semester.
Example: 15
